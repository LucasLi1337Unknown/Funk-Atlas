# Funk Atlas

Static public website for exploring the collected viral funk research catalog.

## Run

Serve this folder with any static HTTP server. For example:

python3 -m http.server 8080

Open http://localhost:8080.

## Publish

GitHub Pages: upload the folder contents to a new repository, then enable Pages from the main branch root.

Vercel: import the folder as an Other/static project with no build command. The folder contains vercel.json.

## Features

Song and artist search, source coverage and date sorting, local saved tracks, top 100 artist views, artist evidence dialogs, source links, dataset download, responsive layout.

## Data

Snapshot: 22 October 2026. The catalog is incomplete and genre/virality classifications are provisional. See the in-site methodology before interpreting the rankings. Saved tracks are stored only in the current browser. The site does not update automatically and does not host audio; listening links open Spotify. Google Fonts are optional and have system-font fallbacks.
